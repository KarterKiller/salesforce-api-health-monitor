# 30–60 second demo script

1. Open a Lightning App Page containing **API Health Monitor**.
2. Point out the configured endpoint row and the empty/unknown state before its first check.
3. Click **Check Now**. Show the success or failure toast and the HTTP status, duration, and check timestamp updating from the saved log.
4. Click **Refresh** to show that the result remains after a reload because it is persisted in `API_Health_Log__c`.
5. Briefly show the custom metadata configuration and Named Credential setup, explaining that the browser cannot provide an endpoint URL.

Record only a real configured endpoint and real result. If showing a failure, label it as a deliberate test configuration.
